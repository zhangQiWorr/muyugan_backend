# 学习时间统计接口说明

## 接口概述

学习时间统计接口提供了按周、月、年统计用户学习时间的功能，帮助用户了解自己的学习习惯和进度。

## 接口地址

```
GET /learning/time-statistics
```

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| period | string | 是 | 统计周期，支持: `week`(周)、`month`(月)、`year`(年) |
| user_id | string | 否 | 用户ID（管理员可指定其他用户） |

## 使用示例

### 1. 获取当前周学习时间统计

```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=week" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 2. 获取当前月学习时间统计

```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=month" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 3. 获取当前年学习时间统计

```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=year" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 4. 管理员查看其他用户统计

```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=week&user_id=USER_ID" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

## 错误响应

### 400 Bad Request - 无效统计周期

```json
{
  "detail": "统计周期参数错误，支持: week, month, year"
}
```

### 401 Unauthorized - 未授权访问

```json
{
  "detail": "Not authenticated"
}
```

### 403 Forbidden - 权限不足

```json
{
  "detail": "权限不足"
}
```

### 422 Unprocessable Entity - 缺少必需参数

```json
{
  "detail": [
    {
      "loc": ["query", "period"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}
```

## 注意事项

1. **权限控制**: 普通用户只能查看自己的学习时间统计，管理员可以查看任意用户的统计
2. **时间范围**: 
   - 周统计：当前周（周一到周日）
   - 月统计：当前月份的所有天数
   - 年统计：当前年份的所有月份
3. **数据来源**: 统计数据基于 `LearningProgress` 表中的 `watch_duration` 字段
4. **时长格式**: 提供原始秒数和格式化字符串两种格式
5. **空数据处理**: 没有学习记录的日期/月份会显示时长为0

## 技术实现

- **数据库查询**: 使用 SQLAlchemy 的聚合函数按日期/月份分组统计
- **时间计算**: 基于 Python datetime 模块计算时间范围
- **数据格式化**: 提供人性化的时长显示格式
- **权限验证**: 集成现有的用户认证和权限系统
