# 学习时间统计功能说明

## 功能概述

学习时间统计功能为用户提供了按周、月、年统计学习时间的能力，帮助用户了解自己的学习习惯和进度。该功能基于用户的学习记录数据，提供详细的时间统计和分析。

## 功能特性

### 1. 多维度统计
- **周统计**: 显示当前周（周一到周日）每日学习时间
- **月统计**: 显示当前月份每天学习时间
- **年统计**: 显示当前年每月学习时间

### 2. 数据展示
- 原始时长数据（秒）
- 人性化格式显示（小时、分钟、秒）
- 完整的日期范围信息
- 周期总时长统计

### 3. 权限控制
- 普通用户只能查看自己的学习时间统计
- 管理员可以查看任意用户的统计
- 基于JWT的认证机制

## 技术实现

### 后端实现

#### 1. 数据模型
- **LearningProgress**: 学习进度记录表
- **MediaPlayRecord**: 媒体播放记录表
- 基于 `watch_duration` 字段统计学习时长

#### 2. 服务层 (`LearningService`)
```python
# 主要方法
def get_learning_time_statistics(user_id: str, period: str) -> Dict[str, Any]
def _get_weekly_learning_stats(user_id: str, now: datetime) -> Dict[str, Any]
def _get_monthly_learning_stats(user_id: str, now: datetime) -> Dict[str, Any]
def _get_yearly_learning_stats(user_id: str, now: datetime) -> Dict[str, Any]
def _format_duration(duration_seconds: int) -> str
```

#### 3. API接口 (`/learning/time-statistics`)
- **方法**: GET
- **认证**: Bearer Token
- **参数**: 
  - `period`: 统计周期 (week/month/year)
  - `user_id`: 用户ID（可选，管理员用）

### 前端集成

#### 1. 响应模型
```python
class LearningTimeStatsResponse(BaseModel):
    period: str
    period_name: str
    total_duration: int
    formatted_total_duration: str
    start_date: Optional[str]
    end_date: Optional[str]
    year: Optional[int]
    daily_data: Optional[List[DailyLearningData]]
    monthly_data: Optional[List[MonthlyLearningData]]
```

#### 2. 数据格式
- **周/月统计**: 包含每日详细数据
- **年统计**: 包含每月汇总数据
- 支持空数据处理（无学习记录的日期显示为0）

## 使用指南

### 1. API调用示例

#### 获取周学习时间统计
```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=week" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### 获取月学习时间统计
```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=month" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### 获取年学习时间统计
```bash
curl -X GET "http://localhost:8000/learning/time-statistics?period=year" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 3. 错误处理

#### 常见错误码
- `400 Bad Request`: 统计周期参数错误
- `401 Unauthorized`: 未授权访问
- `403 Forbidden`: 权限不足
- `422 Unprocessable Entity`: 缺少必需参数
- `500 Internal Server Error`: 服务器内部错误

## 部署说明

### 1. 数据库要求
- 确保 `learning_progress` 表存在且有数据
- 确保 `media_play_records` 表存在且有数据
- 建议为 `last_watched_at` 字段添加索引以提高查询性能

### 2. 环境配置
- 确保JWT认证配置正确
- 确保数据库连接正常
- 确保日志配置正确

### 3. 性能优化
- 对于大量数据，建议添加适当的数据库索引
- 考虑添加缓存机制（Redis）以提高查询性能
- 定期清理过期的学习记录数据
